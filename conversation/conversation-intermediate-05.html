05과 조언하고 제안하기🟡 중급

중급 영어회화 · CEFR B1 ~ B2 · 총 12과 중 5번째

책 전체를 순서대로 보려면 중급 영어회화, 같은 자리로 바로 가려면 책 페이지의 이 과를 쓰세요.

05과

조언하고 제안하기

조언은 상대가 받아들일 수 있는 형태로 전해야 합니다. You should 는 강한 지시로 들릴 수 있어 상황에 따라 표현을 바꿉니다.

조언은 내용보다 강도로 받아들여집니다. 상대의 처지에 맞춰 표현을 낮추고, 대안을 함께 제시하며, 조언을 받았을 때 반응하는 표현까지 익힙니다.

조언의 강도 조절

조언은 상대와의 관계와 사안의 무게에 따라 강도를 고릅니다. 윗사람이나 고객에게는 부드러운 형태를 씁니다.

강도표현쓰는 자리
부드러움You might want to ~윗사람·고객
보통Have you thought about ~ing?동료에게 제안
제안Why don't we ~?함께 할 일 제안
권고I'd suggest ~ing근거가 있을 때
강한 권고You should ~급한 상황·친한 사이

💡 You might want to ~ 는 해 볼 만하다는 뜻으로, 지시가 아니라 정보를 주는 방식입니다. 격식 있는 자리에서 가장 안전합니다.

대안을 함께 제시하기

하나만 제안하면 Yes/No 로 끝납니다. 대안을 함께 주면 상대가 고를 수 있어 대화가 이어집니다.

We could either split the order or delay the second half. Which would you prefer?
주문을 나누거나 후반부를 미룰 수 있습니다. 어느 쪽이 좋으세요?
One option is to extend the deadline. Another is to add a second team.
한 가지 방법은 기한을 늘리는 것이고, 다른 방법은 인력을 더 넣는 것입니다.

💡 either A or B 는 둘 중 하나, Which would you prefer? 는 선택을 묻는 표현입니다. 선택지를 주면 상대가 결정하기 쉬워집니다.

표현 확장 — 조언의 강도 조절

같은 조언도 상대와의 관계와 상황에 따라 표현을 골라 씁니다. 강한 표현일수록 급한 상황에서만 꺼냅니다.

강도표현쓰는 자리
강한 조언You'd better ~정말 급한 상황
일반 조언You should ~동료 사이
완곡한 조언You might want to ~윗사람·고객
제안How about ~ing?함께 정할 때
가능성 제시It might help to ~선택지를 줄 때

💡 You'd better 는 지시처럼 들려서 윗사람에게는 권하지 않습니다.

실전 대화 — 대안과 함께 조언하기

조언은 상대의 상황을 한 번 확인하고 나서 꺼냅니다. 대안을 함께 주면 거절당해도 관계가 남습니다.

The report is due tomorrow, isn't it?
보고서가 내일까지죠?
Yes, so you might want to send the draft today.
네, 그래서 오늘 초안을 보내는 게 좋겠어요.
Good idea. I'll send it after lunch.
좋은 생각이에요. 점심 후에 보낼게요.

조언을 구하고 반응하는 표현

조언을 구할 때는 상황을 짧게 설명하고 선택지를 함께 묻습니다. 조언을 받으면 반응을 먼저 보입니다.

상황표현보기
조언 구하기What would you do in my position?제 입장이면 어떻게 하시겠어요?
판단 요청Do you think that's the right move?그게 맞는 선택일까요?
수락 반응That's a good point.좋은 지적입니다.
유보 반응I'll think about it.생각해 볼게요.
사양 반응Thanks, but I'll try my way first.고맙지만 먼저 제 방식으로 해 볼게요.

💡 조언을 받았을 때 반응이 없으면 상대는 다시 도와줄 이유를 잃습니다.

조언을 구하고 반응하기

조언을 구할 때는 What would you do in my position? 처럼 상대의 입장에서 묻습니다. 조언을 받으면 반응을 보여야 대화가 이어집니다.

상황표현
조언 구하기What would you do in my position?
의견 구하기Do you have any thoughts on this?
받아들이기That's a good point. I'll try that.
보류하기That's worth considering. Let me think it over.

💡 Let me think it over. 는 바로 답하지 않고 생각해 보겠다는 표현입니다. 거절보다 부드럽고 시간을 벌 수 있습니다.

⚠️ 한국어 화자가 자주 하는 실수

  • 윗사람에게 You should ~ 를 그대로 쓰는 실수 — You might want to ~ 로 바꾸면 지시가 아니라 제안이 됩니다.
  • 조언을 받고 아무 반응 없이 넘어가는 실수 — That's a good point. 같은 반응을 넣어야 조언자가 다시 도와줍니다.
  • You'd better ~ 를 윗사람에게 쓰는 실수 — 지시처럼 들립니다. You might want to ~ 로 바꿉니다.
  • 조언만 하고 대안을 말하지 않는 실수 — How about ~ing? 로 선택지를 함께 줍니다.
  • 조언을 부탁해 놓고 바로 반박하는 실수 — 반응을 먼저 보인 뒤 다른 관점을 말합니다.

✏️ 연습 문제 8문항

1. 윗사람에게 쓰기 가장 적합한 조언 표현은?

  1. You'd better rewrite the summary.
  2. You might want to rewrite the summary.
  3. Rewrite the summary.
  4. You must rewrite the summary.
정답과 해설 보기

정답: You might want to rewrite the summary.
윗사람에게는 완곡한 표현인 You might want to ~ 가 어울립니다.

2. 대안을 제안하는 표현은?

  1. How about sending the draft today?
  2. How about send the draft today?
  3. How about to send today?
  4. How about you send today?
정답과 해설 보기

정답: How about sending the draft today?
How about 뒤에는 동명사가 옵니다.

3. 조언을 구하는 표현은?

  1. What would you do in my position?
  2. What you do my position?
  3. How would you in my position?
  4. What do in my position you?
정답과 해설 보기

정답: What would you do in my position?
조언을 구할 때는 What would you do in my position? 을 씁니다.

4. 조언을 받아들이는 반응은?

  1. That's a good point.
  2. I don't care.
  3. You are wrong.
  4. Whatever.
정답과 해설 보기

정답: That's a good point.
반응을 먼저 보이면 조언자가 다시 도와줍니다.

5. A: The report is due tomorrow. — B: ____

  1. You might want to send the draft today.
  2. You'd better sent it.
  3. Send it you today.
  4. It is due, so what.
정답과 해설 보기

정답: You might want to send the draft today.
부담을 낮춘 조언 표현으로 제안합니다.

6. 윗사람에게 가장 부드럽게 조언하는 표현은?

  1. You should change it.
  2. You might want to review the numbers.
  3. You must fix it.
  4. Change it now.
정답과 해설 보기

정답: You might want to review the numbers.
You might want to ~ 는 지시가 아니라 정보를 주는 형태라 격식 있는 자리에 맞습니다.

7. 상대에게 선택을 맡기는 표현은?

  1. You must choose A.
  2. Which would you prefer?
  3. Do it this way.
  4. There is no choice.
정답과 해설 보기

정답: Which would you prefer?
선택지를 제시하고 Which would you prefer? 로 물으면 상대가 고를 수 있습니다.

8. 바로 답하지 않고 생각해 보겠다고 할 때 알맞은 표현은?

  1. I refuse.
  2. Let me think it over.
  3. I don't know anything.
  4. Never ask me again.
정답과 해설 보기

정답: Let me think it over.
think it over 는 충분히 검토해 보겠다는 표현으로 거절보다 부드럽습니다.
