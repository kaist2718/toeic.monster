06과

역제안하고 판을 바꾸기

고급 협상에서는 주어진 선택지 중에 고르지 않고 선택지 자체를 바꿉니다. 이때 상대의 목표를 건드리지 않는 것이 핵심입니다.

고급 협상에서는 주어진 선택지 중에 고르지 않고 선택지 자체를 바꿉니다. 상대의 목표는 인정하고 수단을 바꾸는 것이 핵심입니다.

역제안의 구조

역제안은 상대의 목표를 인정하고, 수단을 바꾸자고 제안하는 형태입니다. 목표 자체를 부정하면 협상이 결렬됩니다.

I understand the target is September. What if we hit it in two phases instead?
9월이 목표라는 것 이해했습니다. 대신 두 단계로 나눠 달성하면 어떨까요?
We both want the same outcome. The question is the route.
우리 목표는 같습니다. 문제는 가는 길입니다.

💡 What if we ~? 는 선택지 자체를 바꾸는 가장 널리 쓰이는 표현입니다. 상대가 거절해도 관계가 상하지 않습니다.

전제를 다시 묻기

협상이 막혔을 때는 조건 자체가 정말 고정인지 확인합니다. 대부분의 제약은 생각보다 유연합니다.

확인할 것표현
고정 조건인지Is the date fixed, or is there room to move?
왜 그 조건인지What's driving the deadline?
우선순위Which matters more, the price or the timing?
범위 조정Could we do a smaller version first?
되돌리기If it doesn't work, can we reverse it?

💡 What's driving the deadline? 은 그 기한을 정하게 만든 것이 무엇인지 묻는 표현입니다. 상대의 진짜 제약을 드러냅니다.

표현 확장 — 조건을 확인하는 질문

협상이 막혔을 때는 조건이 정말 고정인지 확인합니다. 원인을 물으면 협상할 여지가 드러납니다.

확인할 것표현뜻
고정 여부Is the date fixed?날짜가 고정인지 확인합니다.
원인What's driving the deadline?기한을 만든 원인을 묻습니다.
우선순위Which matters more, price or timing?중요한 축을 확인합니다.
범위Could we do a smaller version first?범위를 줄이는 제안입니다.
되돌리기If it doesn't work, can we reverse it?되돌릴 수 있는지 확인합니다.

💡 대부분의 제약은 확인해 보면 생각보다 유연합니다.

실전 대화 — 목표는 지키고 수단 바꾸기

역제안은 목표를 인정하는 문장으로 시작합니다. 목표를 부정하면 협상이 결렬됩니다.

I understand the target is September. What if we hit it in two phases instead?
9월이 목표라는 것은 이해했습니다. 대신 두 단계로 나눠 달성하면 어떨까요?
We both want the same outcome. The question is the route.
우리 목표는 같습니다. 문제는 가는 길입니다.
Let's run it for one quarter. If it doesn't work, we stop, with no penalty.
한 분기만 해 봅시다. 안 되면 중단하고 위약금은 없습니다.

역제안의 세 가지 틀

역제안은 수단 바꾸기, 조건 걸기, 작게 시작하기로 나뉩니다. 상황에 맞는 틀을 골라 씁니다.

틀표현쓰는 자리
수단 바꾸기What if we ~ instead?목표는 두고 수단만 바꿀 때
조건 걸기We could do that if ~조건을 붙여 승낙할 때
작게 시작Let's start with a trial.부담을 낮출 때
범위 조정Could we do a smaller version first?범위를 줄일 때
되돌리기 보장If it doesn't work, we stop.위험을 낮출 때

💡 좋은 역제안은 상대가 거절하기 어렵게 만듭니다.

작게 시작해 크게 가기

결정이 어려운 사안은 부담을 낮춘 제안으로 시작합니다. 되돌릴 수 있다는 조건을 붙이면 승낙 가능성이 크게 올라갑니다.

Let's run it for one quarter. If it doesn't work, we stop — no penalty.
한 분기만 해 봅시다. 안 되면 중단하고, 위약금은 없습니다.
We can start with a trial, then decide on the full roll-out.
시범으로 시작하고, 전체 적용은 그 뒤에 정할 수 있습니다.

💡 no penalty 는 위약금이나 불이익이 없다는 뜻입니다. 되돌릴 수 있다는 조건이 의사결정 부담을 낮춥니다.

⚠️ 한국어 화자가 자주 하는 실수

  • 상대의 목표 자체를 부정하며 역제안하는 실수 — 목표는 인정하고 수단을 바꾸자고 제안합니다.
  • 고정 조건이라고 생각하고 확인하지 않는 실수 — Is the date fixed, or is there room to move? 로 먼저 확인합니다.
  • 수단을 바꾸자고 하면서 목표까지 부정하는 실수 — We both want the same outcome. 으로 목표를 먼저 인정합니다.
  • 되돌릴 수 있는 조건을 붙이지 않는 실수 — If it doesn't work, we stop. 처럼 조건을 명시합니다.
  • 우선순위를 확인하지 않고 가격만 조정하는 실수 — Which matters more, price or timing? 으로 먼저 묻습니다.
