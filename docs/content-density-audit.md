# 콘텐츠 밀도 점검 — 보강 대상과 우선순위

> 점검일: 2026-09-19 · 범위: 사이트 전체 콘텐츠(교재 6권 · 어휘 1,000 · 숙어 126 · 확장 콘텐츠 · 정적 페이지 129)
> 도구: `tools/audit-density.mjs` (`npm run audit:density`) — **보고용**이며 실패로 CI 를 막지 않습니다(`--strict` 를 주면 실패 처리).
> 계기: 「규칙 동사와 불규칙 동사」 표가 3행뿐이던 문법 교재 36과를 심화 보강한 뒤, **같은 문제가 다른 영역에도 남아 있는지** 전체를 같은 잣대로 재어 봤습니다.

## 1. 점검 방법

감사 4종(`audit:content` · `audit:text` · `audit:site` · `audit:a11y`)은 **형식과 표기**를 봅니다. 이 점검은 그 위에
**"학습 자료로 쓸 만한 분량인가"** 를 재는 축을 하나 더 놓은 것입니다. 기준은 문법 교재를 심화 보강한 뒤의 수준을 바닥으로 잡았습니다.

| 항목 | 기준 | 왜 이 기준인가 |
| --- | --- | --- |
| 교재 과: 도입(intro) | 전 과 | 개념을 나열하기 전에 "왜 배우는지"가 없으면 표만 남습니다 |
| 교재 과: 개념(points) | 과당 5개 이상 | 한 과에 판단 기준이 5개 미만이면 문제 유형을 못 덮습니다 |
| 교재 과: 예문(examples) | 과당 5개 이상, 영어(en)+해석(ko) | 예문은 낭독(TTS) 대상이라 소리로도 익힐 수 있어야 합니다 |
| 교재 과: 표 행 | 과당 8행 이상 | 형태 표가 3행이면 "표로 익히라"는 설명을 뒷받침하지 못합니다 |
| 교재 과: note | 과당 4개 이상 | 함정·예외를 짚는 문장이 없으면 오답이 그대로 남습니다 |
| 교재 과: 흔한 실수 | 과당 4개 이상 | 실수 목록이 2개면 대표 오류만 다룹니다 |
| 교재 과: 연습 | 과당 6문항 이상 | 개념 하나를 확인할 문항이 부족합니다 |
| 어휘 예문 | 5단어 이하 비율 10% 이하 | 짧은 예문은 문맥·콜로케이션 학습에 약합니다 |
| 허브 페이지 | 본문 2,500자 이상 | 목록만 있는 허브는 검색 유입 후 이탈 지점이 됩니다 |
| 교재 과 페이지 | 본문 3,500자 이상 | 과 단위 주소는 검색 유입의 최전선입니다 |
| 가이드 | 본문 2,500자 이상 | 전략 콘텐츠는 체류 시간을 만드는 자산입니다 |
| LC 커버리지 | 실제 시험 문항 대비 70% 이상 | 감사 게이트(50%)보다 한 단계 높게 잡은 목표선입니다 |

```bash
npm run audit:density            # 표로 결과만 봅니다 (종료 코드 0)
npm run audit:density -- --strict # 기준 미달이면 종료 코드 1 (게이트로 쓸 때)
```

## 3. 영역별 상세

### 3-1. 교재 — 문법은 끝났고 회화가 남았습니다

```
교재      │ 도입  │ 개념 │ 예문 │ 표행 │ note │ 실수 │ 연습
──────────┼───────┼──────┼──────┼──────┼──────┼──────┼─────
문법 초급 │ 12/12 │ 5.9  │ 5.6  │ 25.9 │ 2.7  │ 5.0  │ 8.0
문법 중급 │ 12/12 │ 5.8  │ 5.4  │ 17.1 │ 2.2  │ 5.0  │ 8.0
문법 고급 │ 12/12 │ 6.3  │ 11.6 │ 9.7  │ 4.0  │ 5.0  │ 8.0
회화 초급 │ 0/12  │ 3.0  │ 2.8  │ 6.6  │ 3.0  │ 2.0  │ 3.0
회화 중급 │ 0/12  │ 3.0  │ 2.5  │ 7.8  │ 3.0  │ 2.0  │ 3.0
회화 고급 │ 0/12  │ 3.0  │ 2.2  │ 9.5  │ 3.0  │ 2.0  │ 3.0
```

회화 교재는 데이터 구조부터 다릅니다 — `points` 에 **`examples`(영어·해석) 필드가 아예 없어서**
영어 문장은 표 안에만 들어 있습니다. 그래서 회화 과 페이지에는 낭독 버튼이 **2개**(문법 과 페이지는 14개)뿐입니다.
수치를 채우는 동시에 **영어 문장을 `examples` 로 옮겨 듣기 대상으로 만드는 것**이 이 보강의 핵심입니다.

### 3-2. 페이지 분량 — 얇은 자리가 회화·허브·가이드에 몰려 있습니다

| 그룹 | 페이지 | 중앙값 | 최소 | 최대 |
| --- | --- | --- | --- | --- |
| grammar | 41 | 4,893 | 3,158 | 59,483 |
| units | 34 | 5,252 | 2,050 | 11,990 |
| conversation | 40 | 2,775 | 1,869 | 25,123 |
| guides | 10 | 2,280 | 1,960 | 2,836 |

- 교재 과 페이지 36개(전부 회화)가 3,500자 미만입니다 — 회화 교재 심화 보강이 해결합니다.
- 허브 3개가 2,500자 미만입니다. `grammar/index.html` 는 「교재 목록 · 한눈에 보기 · 단계별 안내 · 학습 순서 · 연습 문제 활용법 · 자주 묻는 질문」 6개 블록인데,
  `conversation/index.html` 는 4개(교재 목록 · 학습 순서 · 이 교재를 만든 기준 · 자주 묻는 질문), `units/index.html` 는 3개(유닛 목록 · 자주 묻는 질문 · 함께 보면 좋은 자료),
  `guides/index.html` 는 3개(가이드 목록 · 어떤 순서로 읽으면 좋을까요 · 자주 묻는 질문)입니다. **한눈에 보기·활용법 블록이 문법 허브에만 있습니다.**
- 가이드 6편이 2,500자 미만입니다 — `guides/part-7-double-passage.html` 1,966자, `guides/vocabulary-30day.html` 2,014자,
  `guides/listening-numbers.html` 2,088자, `guides/part-6-text-completion.html` 2,138자,
  `guides/part-2-traps.html` 2,280자, `guides/part-5-word-forms.html` 2,461자.

### 3-3. LC 커버리지 — Part 3 이 가장 얇습니다

| 파트 | 보유/실제 | 비율 |
| --- | --- | --- |
| Part 1 | 19/6 | 317% |
| Part 2 | 25/25 | 100% |
| Part 3 | 24/39 | **62%** |
| Part 4 | 21/30 | 70% |

세트 수로는 대화 8세트·담화 7세트입니다. 실제 구성(대화 13세트·담화 10세트)에 맞추려면
**대화 5세트(15문항) + 담화 3세트(9문항)** 가 더 필요합니다.

### 3-4. 어휘 — 62개 예문이 5단어 이하입니다

평균 7.2단어로 기준(10% 이하)은 통과하지만, 62개는 예문 길이가 5단어 이하입니다.
이 단어들은 콜로케이션·문맥 정보가 거의 없어 암기 카드의 예문 역할을 못 합니다.

## 4. 우선순위 (다음 작업)

| 순위 | 작업 | 범위 | 끝났다고 보는 기준 | 검증 |
| --- | --- | --- | --- | --- |
| **P0** | 회화 교재 3권 36과 심화 | `data/conversation-*.js` · `tools/build-pages.mjs`(회화 예문 렌더) | 과당 도입 1 · 개념 5~7 · 예문 8+ (en/ko, 낭독) · 표 8행+ · note 4+ · 실수 5 · 연습 8 → 연습 108 → **288** | `npm run audit:density` 에서 회화 3권 통과, `npm test` 문항 수 일치 |
| **P1** | Part 3·4 LC 보강 | `data/app-data.js` 의 `PART34_SETS` | 대화 13세트·담화 10세트 (문항 39·30) 로 커버리지 100% | `npm run audit:content` 커버리지 표 |
| **P2** | 허브 3곳·가이드 6편 분량 | `tools/build-pages.mjs`(허브 블록) · `data/extra.js`(`guides`) | 허브·가이드 모두 2,500자 이상 | `npm run audit:density` 의 페이지 분량 표 |
| **P3** | 어휘 짧은 예문 62개 + 문법 note | `data/unit*.js` · `data/grammar-{basic,intermediate}.js` | 5단어 이하 5% 이하, 문법 note 과당 4+ | `npm run audit:density` · `npm run audit:text` |

### P0 을 먼저 하는 이유

1. **사용자에게 바로 보이는 격차**입니다 — 같은 사이트 안에서 문법 교재 과 페이지는 약 5,000자, 회화는 약 2,700자입니다.
2. **문법 교재에서 한 번 해 본 작업의 재적용**이라 위험이 낮습니다(스키마만 `examples` 를 더하면 되고, 감사 규칙은 그대로 통과).
3. 회화 교재는 `docs/conversation-research.md` 5절의 **"앱 내 회화 연습"** 후보의 전제이기도 합니다(연습 문항이 3개뿐이면 앱에서 풀 거리가 없습니다).

## 6. 기준을 올리는 규칙

이 문서의 기준은 **지금의 바닥**입니다. P0~P3 을 끝내면 `tools/audit-density.mjs` 의 `BASELINE` 을
그때의 실제 값(예: 회화 과당 연습 8문항, 허브 3,500자)으로 **함께 올려 주세요**.
기준이 낮게 남으면 같은 회귀가 다시 쌓입니다.

```bash
npm run audit:density                  # 현재 상태 확인
npm run audit:density -- --strict      # 게이트로 승격할 때
```
