## 1. 점검 방법

감사 4종(`audit:content` · `audit:text` · `audit:site` · `audit:a11y`)은 **형식과 표기**를 봅니다. 이 점검은 그 위에
**"학습 자료로 쓸 만한 분량인가"** 를 재는 축을 하나 더 놓은 것입니다. 기준은 문법 교재를 심화 보강한 뒤의 수준을 바닥으로 잡았습니다.

| 항목 | 기준 | 왜 이 기준인가 |
| --- | --- | --- |
| 교재 과: 도입(intro) | 전 과 | 개념을 나열하기 전에 "왜 배우는지"가 없으면 표만 남습니다 |
| 교재 과: 개념(points) | 과당 5개 이상 | 한 과에 판단 기준이 5개 미만이면 문제 유형을 못 덮습니다 |
| 교재 과: 예문(examples) | 과당 5개 이상, 영어(en)+해석(ko) | 예문은 낭독(TTS) 대상이라 소리로도 익힐 수 있어야 합니다 |
| 교재 과: 표 행 | 과당 8행 이상 | 형태 표가 3행이면 "표로 익히라"는 설명을 뒷받침하지 못합니다 |
| 교재 과: note | 과당 4개 이상 | 함정·예외를 짚는 문장이 없으면 오답이 그대로 남습니다 |
| 교재 과: 흔한 실수 | 과당 4개 이상 | 실수 목록이 2개면 대표 오류만 다룹니다 |
| 교재 과: 연습 | 과당 6문항 이상 | 개념 하나를 확인할 문항이 부족합니다 |
| 어휘 예문 | 5단어 이하 비율 10% 이하 | 짧은 예문은 문맥·콜로케이션 학습에 약합니다 |
| 허브 페이지 | 본문 2,500자 이상 | 목록만 있는 허브는 검색 유입 후 이탈 지점이 됩니다 |
| 교재 과 페이지 | 본문 3,500자 이상 | 과 단위 주소는 검색 유입의 최전선입니다 |
| 가이드 | 본문 2,500자 이상 | 전략 콘텐츠는 체류 시간을 만드는 자산입니다 |
| LC 커버리지 | 실제 시험 문항 대비 70% 이상 | 감사 게이트(50%)보다 한 단계 높게 잡은 목표선입니다 |

```bash
npm run audit:density            # 표로 결과만 봅니다 (종료 코드 0)
npm run audit:density -- --strict # 기준 미달이면 종료 코드 1 (게이트로 쓸 때)
```

## 3. 영역별 상세

### 3-1. 교재 — 문법·회화 모두 통과

```
교재      │ 도입  │ 개념 │ 예문 │ 표행 │ note │ 실수 │ 연습
──────────┼───────┼──────┼──────┼──────┼──────┼──────┼─────
문법 초급 │ 12/12 │ 5.9  │ 5.6  │ 25.9 │ 5.9  │ 5.0  │ 8.0
문법 중급 │ 12/12 │ 5.8  │ 5.4  │ 17.1 │ 5.8  │ 5.0  │ 8.0
문법 고급 │ 12/12 │ 6.3  │ 11.6 │ 9.7  │ 4.0  │ 5.0  │ 8.0
회화 초급 │ 12/12 │ 6.0  │ 5.8  │ 16.3 │ 5.0  │ 5.0  │ 8.0
회화 중급 │ 12/12 │ 6.0  │ 5.5  │ 17.8 │ 5.0  │ 5.0  │ 8.0
회화 고급 │ 12/12 │ 6.0  │ 5.2  │ 19.5 │ 5.0  │ 5.0  │ 8.0
```

회화 교재는 데이터 구조부터 달랐습니다 — `points` 에 **`examples`(영어·해석) 필드가 아예 없어서**
영어 문장은 표 안에만 들어 있었고, 그래서 회화 과 페이지의 낭독 버튼이 **2개**(문법 과 페이지는 14개)뿐이었습니다.
보강에서 개념 3개를 더하면서 **영어 문장을 `examples` 로 옮겨 듣기 대상으로 만들었습니다**(과 페이지 낭독 버튼 2개 → **3~7개**).
연습 문항은 회화 3권 36과 모두 과당 8문항이 되어 108 → **288문항**입니다(문법 교재와 동일).

### 3-2. 페이지 분량 — 기준 이상

| 그룹 | 페이지 | 중앙값 | 최소 | 최대 |

- 허브 3곳(`conversation/` 2,551자 · `guides/` 2,625자 · `units/` 2,787자)은 모두 2,500자를 넘겼습니다.
  문법 허브에만 있던 「한눈에 보기 · 활용법」 블록을 세 허브에도 넣어 **목록 앞에 읽을거리**를 두었습니다.
- 가이드 9편 중 6편이 2,500자 미만이었고(최소 1,966자), 각 편에 **「실전 적용 순서 · 계획을 지키는 방법 · 판단 기준」** 같은 절을 더해 전 편 2,500자 이상으로 맞췄습니다.
- 교재 과 페이지 36개(전부 회화)가 3,500자 미만이던 문제는 회화 교재 심화 보강으로 함께 해결됐습니다.

### 3-4. 어휘 — 5단어 이하 예문 0개

평균 7.2단어였고 62개 예문이 5단어 이하였습니다. 이 단어들은 콜로케이션·문맥 정보가 거의 없어 암기 카드의 예문 역할을 못 했습니다.
62개를 모두 **7단어 이상 문장으로 다시 쓰고, 해석과 예문 한글 발음을 함께 갱신**했습니다.
