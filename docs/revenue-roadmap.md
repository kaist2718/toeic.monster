## 0. 한 장 요약

**진단.** 이 사이트는 "돈이 되는 구조"가 아니라 **유입 자산**을 이미 갖고 있습니다 — 색인 대상 페이지 126개, 어휘 1,000개, 교재 72과(연습 576문항), 가이드 9편, 숏폼 자동 발행 도구(`promo/`). 반대로 **수익 인프라는 0** 입니다(계정 없음, 결제 없음, 광고 없음, 이메일 수집 없음).

**결론 5줄.**

1. 광고·제휴만으로는 **월 10만원대**가 현실적 상한선입니다 — 트래픽이 10배가 되어도 마찬가지입니다(§5-3). 교재 제휴 수수료는 건당 수백 원 수준입니다.
2. 돈이 되는 지점은 **디지털 부가자료**(웹 밖 산출물)와 **B2B(학원·학교)** 입니다. 둘 다 「무료 웹 기능」을 건드리지 않고 만들 수 있습니다.
3. 구독·계정은 **매출의 크기보다 재방문을 만드는 장치**로 먼저 검토합니다. 서버가 필요해져 이 시점에 호스팅 이전 문제가 함께 옵니다(§8-3).
4. 가장 큰 병목은 수익 모델이 아니라 **유입과 측정**입니다. 지금은 UA(방문자)·전환 데이터가 없어 어떤 판단도 검증할 수 없습니다 → **Phase 0(측정)이 첫 작업**입니다.
5. 1인 운영이므로 판단 기준은 "월 매출"이 아니라 **시간당 수익**입니다(§5-5). 기본 시나리오에서 월 55만원 × 40시간 ≈ 시급 1.4만원이라, 이보다 낮으면 **상품을 키우거나 손을 떼는 결정**을 해야 합니다.

**12개월 목표(기본 시나리오).** MAU 10,000 · 월 매출 ₩575,000 · 순이익률 80%대(고정비 사실상 0원) · 상품 누적 판매 300건 · 학원 라이선스 1곳.

**먼저 해야 할 3가지.** ① 4주간 기준선 측정(이벤트 설계 → §11) ② FAQ·랜딩의 "모든 기능이 무료" 문구 정리(§6-4) ③ 상품 1종(전체 단어장 PDF + 발음 MP3) 제작과 판매 채널 개설(§7, Phase 2).

## 2. 시장 · 수요 구조

### 2-1. 수요의 성격

| 사실 | 수익화 함의 |
| --- | --- |
| 응시료 52,500원 · 연 26회 시행(2월·8월은 월 3회) | 시험 전 2~6주에 수요가 몰리는 **계절성**. 성수기에 상품·프로모션을 집중 |
| 응시자 1인당 연평균 응시 1.8회 · 63%가 연 1회 | **단명하는 고객**. 구독보다 **일회성 상품**이 맞고, 재방문은 시험 주기(3~6개월)로 설계 |
| 목표 점수대가 명확(700/800/900) | 상품을 **점수대별로 쪼갤 수 있음**(어휘 800+ / 900 도전 등) |
| 취업·승진·졸업 요건 등 **불가피 지출** | 지불 의사 자체는 있음. 문제는 **신뢰**(§3) |

### 2-2. 지불 의사 지형 (추정)

| 지출 항목 | 시장 가격대 | 우리 적합도 |
| --- | --- | --- |
| 어학 앱 구독 | 월 1만~4만원대(무료 플랜 제한형) | 중 — 계정 필요, Phase 3 |
| 인강 단과 | 1.5만~3만원 | 낮음(제작비) — 대신 **제휴** 대상 |
| 보장반 | 39만원 안팎 | 매우 낮음(환급 리스크) — 제휴만 |
| 종이 교재 | 1.5만~2만원 | **중상** — 우리 PDF 상품의 앵커 |
| 디지털 부가자료 | 3천~1.3만원 | **상** — 제작비 0원, 즉시 판매 가능 |
| 학원·학교 도입 | 월 수만 원~연 수십만 원 | **상(단가 최고)** — 판매 노력 필요 |

### 2-3. 경쟁 지형에서 비어 있는 자리

1. **"설명이 있는 무료 어휘/문법"** — 무료 앱은 대개 문제만 풀게 하고 설명이 얕음.
2. **"가입 없이 바로"** — 대부분 가입·앱 설치를 요구.
3. **"인쇄물로 넘어가는 다리"** — 웹에서 확인한 오답을 종이/PDF로 가져가는 흐름이 없음 → 이것이 우리 상품 라인업(§6-2)의 정체성.

## 5. 단위 경제성 (Unit Economics)

> 모든 수치는 **가정**입니다. §11 의 측정이 끝나면 실측값으로 이 표만 교체하면 됩니다(문서 구조를 그대로 두기 위한 설계).

### 5-1. 트래픽 시나리오

| 시나리오 | MAU | 월 PV | 전제 |
| --- | --- | --- | --- |
| 보수 | 3,000 | 12,000 | 현재 수준 또는 소폭 성장 |
| 기본 | 10,000 | 40,000 | 검색 유입이 자리 잡은 상태 |
| 낙관 | 30,000 | 120,000 | 숏폼·커뮤니티가 붙고 교재 페이지가 상위 노출 |

### 5-2. 모델별 산식

| 모델 | 산식(가정) |
| --- | --- |
| 광고 | 월 PV ÷ 1,000 × RPM 2,000원 |

### 5-3. 시나리오별 월 매출 (추정)

**읽는 법 3가지**

1. 광고+제휴(1·2번)를 합쳐도 기본 시나리오에서 **월 11만원**입니다. 트래픽을 10배로 만들어도 50만원대 — **광고는 주 수익원이 될 수 없습니다.**
2. 매출의 **약 52%**(기본·낙관 모두)가 디지털 상품 한 줄에서 나옵니다. 우선순위가 여기여야 하는 이유입니다.
3. 구독은 초기 기여가 작지만 **누적**됩니다(해지 없으면 12개월 차에 12배). 재방문 지표가 받쳐 줄 때만 투자합니다.

### 8-4. 호스팅 이전 판단 (중요)

GitHub Pages 정책은 "온라인 사업·전자상거래·상업적 SaaS 목적의 무료 호스팅" 용도를 허용하지 않습니다(§15 출처). 해석 여지가 있지만 **자체 결제·구독을 사이트 안에 붙이는 순간** 위험이 실질화됩니다.

- **광고·제휴 수준**: 유지 검토(위험 낮음)
- **자체 결제·계정 도입 시**: Cloudflare Pages 등 정적 호스팅으로 이전 — 도구 대부분이 `_site/` 구성 후 그대로 배포 가능(§10 Phase 3 게이트)

| **1. 무료 지면 수익화** | 1~3개월 | 첫 수익 만들기 | 제휴 카드 1곳 · 문구 정리 · 문의 창구 | 제휴 CTR ≥ 0.5% · 학습 지표 악화 없음 | CTR < 0.2% → 지면·소재 교체 |
| **2. 상품 판매** | 3~6개월 | 주 수익원 확보 | PDF·MP3 제작 자동화 · 판매 채널 · 상품 페이지 | 월 10건 이상 · 전환율 ≥ 0.2% · 환불률 < 10% | 3개월 누적 30건 미만 → 가격·구성 재설계 |
| **3. 반복·B2B** | 6~12개월 | 누적 매출과 단가 | 계정·동기화(선택) · 학원 라이선스 1곳 · 이메일 재방문 | 재방문율 ≥ 25% · 구독 20명 또는 B2B 1곳 | 시간당 수익 1만원 미만 3개월 → 투자 중단 |
| **4. 확장** | 12~24개월 | 규모·영역 확장 | 앱 래핑 · 스피킹/오픽 · 라이선스 3곳 | 월 매출 100만원 이상 | 유지비 > 매출 증가분 → 동결 |

**각 Phase 착수 전 공통 확인**: `npm run audit` · `npm audit`(외부 의존성 0 유지) · 학습 지표가 악화되지 않았는지(§11-3).
