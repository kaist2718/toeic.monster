> 대상: toeic.monster (정적 사이트 · 서버 없음 · `index.html` + `data/*.js` · 빌드 스크립트로 정적 페이지 생성)

## 1. 조사 대상과 확인한 사실

### 1-1. 회화를 "상황"으로 나누는 사이트

| 사이트 | 확인한 구성 | 배울 점 |
| --- | --- | --- |
| **British Council LearnEnglish** (`learnenglish.britishcouncil.org`) | CEFR 6단계(A1~C2)를 기준으로 자료를 나누고, 회화·영상 시리즈를 **상황 에피소드**(예: 처음 만나는 장면) 단위로 제공. 레벨별로 "무엇을 할 수 있어야 하는지"를 먼저 설명 | 회화는 **레벨 축과 상황 축**을 함께 가져야 한다. 레벨만 있으면 어디서 시작할지 모르고, 상황만 있으면 난이도를 알 수 없다 |
| **VOA Let's Learn English** (`learningenglish.voanews.com`) | **Level 1·Level 2** 두 단계 과정. 레슨마다 영상 + 활동 + 퀴즈 + 인쇄용 워크시트를 붙이고, 말하기·어휘·쓰기를 한 레슨 안에서 함께 다룸 | 단계는 **두세 개로 크게** 나누는 편이 학습자가 고르기 쉽다. 한 과에 듣기·말하기·확인 문제를 함께 담는다 |
| **ELLLO** (`elllo.org`) | 3,000개 이상의 레슨을 **레벨별로 묶고**, 레슨마다 오디오·영상 + 스크립트 + 어휘 + 상호작용 퀴즈 제공 | 회화 자료는 **스크립트와 확인 문제가 붙어야** 학습이 된다. 듣고 끝나는 자료는 복습이 안 된다 |
| **BBC Learning English** | 코스를 **단원(unit)** 으로 묶고, 단원마다 설명 + 영상·오디오 + 퀴즈 | 한 단원 = 설명 + 소리 + 확인 문제의 3종 세트 |
| **Speak·Cake·ELSA 류 앱** | 말하기 자체를 반복 훈련시키고, 기능(주문·여행·면접)을 골라 시작하게 함 | 시작점을 **"오늘 겪을 상황"** 으로 잡으면 진입 장벽이 낮다 |
| **국내 회화 교재·인강의 관행** | "왕초보 → 기초 → 중급"처럼 **3단계 시리즈**로 나뉘고, 각 단계가 전화·식당·여행 같은 **상황 단위**로 구성 | 단계 이름이 곧 검색 키워드다. 문법 교재(`그래머 인 유즈`식 3단계)와 **같은 3단계 이름**을 쓰면 사이트 안에서 두 교재가 나란히 선다 |

### 1-2. 조사에서 뽑은 5가지 설계 원칙

1. **축은 문법 항목이 아니라 상황(기능)** — 인사·주문·길 묻기·전화·협상. 학습자는 "현재완료를 배운다"보다 "카페에서 주문한다"를 먼저 찾는다.
2. **단계는 세 이름으로 고정하고 CEFR을 병기** — 초급(A1~A2) / 중급(B1~B2) / 고급(C1). 문법 교재와 **같은 이름·같은 표기**를 써서 사이트 안에서 일관되게 만든다.
3. **한 과는 "상황 요약 → 표현 표 → 예문 → 흔한 실수 → 연습 문제"** — BBC·ELLLO의 3종 세트에 `흔한 실수`와 `연습 문제`를 더한다. 실수 항목이 없으면 한국어 직역 투가 그대로 굳는다.
4. **말하기는 눈이 아니라 입으로** — 과마다 발음·억양 안내를 따로 두고, 예문에 🔊 를 붙여 소리로 확인하게 한다. 회화 교재인데 소리 없이 읽기만 하면 효과가 없다.
5. **문법 교재와 같은 데이터 구조** — 두 교재를 같은 방식으로 읽고 같은 연습 문제 형식으로 풀게 한다. 학습자가 새로 배울 조작이 없어야 한다.

### 1-3. 우리 사이트와의 관계

| 구분 | 기존 콘텐츠 | 이번 추가 콘텐츠 |
| --- | --- | --- |
| 성격 | `🗒️ 말하기·쓰기 템플릿`(표현 12세트), `🎙️ Speaking 유형별 연습`, `🗣️ 말하기·쓰기 확장 연습` — 시험 직전에 쓰는 표현·연습 | **단계별 회화 교재 3권** (36과) — 상황을 순서대로 쌓는 학습 |
| 분량 | 템플릿 12세트 / 연습 카드 26개 | 과당 도입 + 개념 6개 + 표 16~20행 + 예문 5~6개(en/ko, 낭독) + note 5개 + 실수 5개 + 연습 8문항 (초판은 연습 3문항 → 심화 보강으로 8문항) |
| 목적 | TOEIC S&W 답변 틀 만들기 | **일상·업무 회화를 처음부터 말로 쌓기** |
| 진입 경로 | 앱 내 카드 | 검색 유입용 정적 페이지(`conversation/*.html`) |

기존 콘텐츠는 "답변 틀"이고, 새 콘텐츠는 "말하기 교재"입니다. 서로 대체하지 않고, 템플릿에서 막힌 학습자가 교재로 내려가 표현을 다시 쌓도록 **난이도 사다리**로 연결합니다.

## 2. 설계한 3단계 커리큘럼

### 2-1. 초급 — 기초 영어회화 (A1~A2, 12과)

> 부제: 인사부터 전화까지, 살아남는 12가지 상황

| 과 | 상황 | 한 줄 |
| --- | --- | --- |
| 1 | 인사하고 첫 인사 나누기 | 시간대별 인사, 처음/아는 사람 구분, 되묻기 |
| 2 | 자기소개 | 이름·나이·출신·직업 |
| 3 | 사람 소개하고 안부 묻기 | 제3자 소개, 근황 묻기 |
| 4 | 숫자·시간·날짜 말하기 | 가격·시각·요일 읽기 |
| 5 | 물건 사고 가격 묻기 | 사이즈·교환·카드 결제 |
| 6 | 카페와 식당에서 주문하기 | 주문·추천 요청·계산 |
| 7 | 길 묻고 대중교통 이용하기 | 위치 묻기·표 사기·환승 |
| 8 | 하루 일과와 약속 정하기 | 시간 제안·수락·연기 |
| 9 | 날씨와 기분 말하기 | 날씨 표현·컨디션 |
| 10 | 취미와 좋아하는 것 말하기 | 좋아함·싫어함·빈도 |
| 11 | 부탁하고 도와주기 | 정중한 요청·수락·거절 |
| 12 | 전화와 메시지로 연락하기 | 연결 요청·받아쓰기·문자 |

초급의 목표는 **"짧더라도 먼저 말을 걸고, 되묻고, 대답을 마친다"** 입니다. 문법 설명은 최소화하고 표현을 통째로 외우게 합니다.

### 2-2. 중급 — 중급 영어회화 (B1~B2, 12과)

> 부제: 의견·조율·설득까지, 대화를 끌고 가는 12가지 기술

| 과 | 기술 | 한 줄 |
| --- | --- | --- |
| 1 | 의견 말하기와 강도 조절 | 확신 강도별 표현, 인정 후 반론 |
| 2 | 계획과 일정 조율하기 | 일정 제안·충돌 조정 |
| 3 | 경험 이야기하기 | 시제 전환, 일화 구성 |
| 4 | 문제를 말하고 해결 요청하기 | 증상 설명 → 요청 |
| 5 | 조언하고 제안하기 | 조언 강도 조절 |
| 6 | 동의하고 반대하기 | 부분 동의·완곡한 반대 |
| 7 | 사과하고 책임지기 | 사과 범위와 보상 |
| 8 | 회의에서 발언하기 | 발언권 얻기·요약·확인 |
| 9 | 협상하고 조건 맞추기 | 조건·대안·마감 |
| 10 | 추측하고 확신 정도 나타내기 | must/might/seem |
| 11 | 들은 것을 전하고 확인하기 | 전달·재확인 |
| 12 | 감정 표현하고 공감하기 | 감정 어휘·공감 반응 |

중급의 목표는 **"대화를 끊기지 않게 끌고 가는 것"** 입니다. 여기서부터 실수 항목이 "문법 오류"보다 **"관계를 상하게 하는 말투"** 에 집중됩니다.

### 2-3. 고급 — 고급 영어회화 (C1, 12과)

> 부제: 말의 온도와 책임을 조절하는 12가지 기술

| 과 | 기술 | 한 줄 |
| --- | --- | --- |
| 1 | 완곡하게 말하고 책임 한계 두기 | 헤지 표현·책임 범위 |
| 2 | 격식과 비격식 전환하기 | 자리별 표현 교체 |
| 3 | 설득하고 반론을 미리 막기 | 근거 배치·선제 반박 |
| 4 | 정보의 한계와 불확실성 다루기 | 출처·추정 표시 |
| 5 | 갈등 완화하고 중재하기 | 입장 분리·공통점 |
| 6 | 역제안하고 판을 바꾸기 | 조건 재설정 |
| 7 | 미묘한 뉘앙스 구분하기 | 비슷한 표현의 온도차 |
| 8 | 관용 표현을 업무 대화에 쓰기 | 관용구의 적정선 |
| 9 | 유머와 아이러니의 경계 | 웃음의 안전선 |
| 10 | 담화 표지로 흐름 만들기 | 연결·전환·정리 |
| 11 | 발표하고 설명 이끌기 | 설명 구조·질문 처리 |
| 12 | 문화 차이와 예의의 결 | 직접성·거리감 |

고급의 목표는 **"무엇을 말할지"가 아니라 "어떤 온도로 말할지"** 입니다. 같은 내용도 어떻게 말하느냐가 결과를 바꾼다는 것을 과마다 대비 예문으로 보여 줍니다.

## 3. 데이터·렌더링 구조

기존 규약(문법 교재)을 그대로 따릅니다.

| 항목 | 결정 |
| --- | --- |
| 데이터 | `data/conversation-basic.js` · `-intermediate.js` · `-advanced.js` 가 `window.CONVERSATION_BOOKS` 에 교재를 하나씩 push |
| 생성 | `tools/build-pages.mjs` 가 `conversation/index.html`(허브) + `conversation/<id>.html`(교재 3권) 생성 |
| 검증 | `audit-site`(링크·앵커·사이트맵·문서 수치) · `audit-content`(과 번호·정답 보기 포함) · `audit-text`(맞춤법·TTS) |
| 진입 | 홈 `📕 회화 교재 3단계` 섹션 + 섹션 이동 칩(`말하기·쓰기` 묶음) · `<noscript>` 정적 링크 |

### 3-1. 한 과의 데이터 구조

`상황 요약(summary)` → `표현(points)` → `형태·표현 표(table)` → `예문(examples)` → `흔한 실수(mistakes)` → `연습 문제(practice)`.

`points` 항목은 `h`(제목) + `body`(설명) + `table` 또는 `examples` + `note`(억양·뉘앙스 안내)로 이루어집니다.
연습 문제는 정답과 해설을 `<details>` 로 접어 두어 스스로 풀고 확인할 수 있게 했습니다.

### 3-2. 앱과의 연동

| 기능 | 동작 |
| --- | --- |
| 교재 카드 | 홈 `📕 회화 교재 3단계` 섹션이 `window.CONVERSATION_BOOKS` 로 단계·CEFR·과 수·연습 문항 수를 카드로 그립니다 |
| 예문 발음 | 정적 교재 페이지의 🔊 버튼. 앱의 `toeic1000_ttsvoice`·`toeic1000_ttslang`·`toeic1000_ttsrate` 를 그대로 읽어 **앱에서 고른 목소리·속도가 교재에서도 유지**됩니다 |
| 인쇄 | 교재 페이지는 인쇄용 CSS 를 포함해 과 단위로 뽑아 쓸 수 있습니다 |

> 앱 안에서 회화 연습 문제를 풀게 하는 것은 **이번 범위에 넣지 않았습니다.** 문법 교재에는 `✏️ 문법 문제 풀이` 와 오답노트가 있으므로, 회화도 같은 방식으로 붙일 수 있습니다(아래 5절).
