# 수익화 설계 — 교재 제휴 + 유료 부가자료

> 대상: toeic.monster (정적 사이트 · GitHub Pages · 서버 없음)
> 목적: 홈페이지 수익화. 후원은 부가 수단으로만 두고, 제휴와 유료 부가자료를 주 수단으로 설계한다.

---

## 0. 전제와 원칙

| 항목 | 현재 상태 |
|---|---|
| 호스팅 | 정적 (GitHub Pages, `CNAME`) — **서버 없음** |
| 학습 데이터 | 브라우저 `localStorage`에만 저장 |
| 코드 구조 | `index.html` 단일 파일(약 6,500줄, 인라인 CSS/JS) + 사전 렌더링 `units/*.html` + `data/*.js` |
| 현재 포지션 | "모든 기능이 무료입니다. 회원가입이나 결제 없이…" (`index.html` 70행 JSON-LD, 2,548행 FAQ) |

**핵심 원칙**

1. **웹 학습 기능은 영구 무료로 유지한다.** (퀴즈·오답노트·시험모드·암기카드)
2. **유료는 "웹 밖 부가 자료"만** 판매한다. (PDF·오디오·인쇄물·모의고사 파일)
3. 기존 무료 기능을 유료로 **전환하지 않는다.** (신뢰 손상 및 기존 사용자 이탈 방지)
4. 광고·제휴는 **섹션 1개 원칙** — 학습 UX를 해치지 않는다.

> ⚠️ 1번 원칙을 지키려면 FAQ/랜딩의 "모든 기능이 무료" 문구를 **"웹 학습 기능은 모두 무료, 부가 자료는 유료"** 로 정리해야 한다. 그대로 두면 실제와 어긋나 신뢰 문제가 된다.

## 1. 교재·인강 제휴 영역 설계

### 1-1. 제휴 채널

| 채널 | 특징 | 비고 |
|---|---|---|
| **쿠팡파트너스** | 진입 쉬움, 도서 포함 전 카테고리 | **고지 문구 의무**, 정책 변경 잦음 |
| **알라딘 TTB** | 도서 특화, 링크 단위 수익 | 도서 요율 낮음 |
| **예스24 제휴프로그램** | 도서 제휴 | 도서 요율 낮음 |
| **교보문고 제휴** | 도서 제휴 | 동일 |
| **인강 제휴** (해커스·YBM 등) | **단가 높음** | 제휴 승인·별도 채널 확인 필요 |

**현실 인식**: 도서 제휴 요율은 낮은 한 자릿수 초반 수준이라 **교재 1건당 수익은 수십 원** 규모다. 교재 배너만으로 유의미한 수익을 기대하면 안 된다. 실질 수익은 **인강·환급반·문제집 패키지** 쪽이 크므로 우선순위는 **인강 제휴 > 교재 제휴**다.

### 1-2. 배치 위치 (전환율 높은 순)

| 순위 | 위치 | 이유 | 구현 대상 |
|---|---|---|---|
| 1 | **시험 모드 결과 화면** (예상 점수 직후) | 성취·불안이 최고점인 순간 | `index.html` JS 결과 렌더링부 |
| 2 | **유닛 학습 완료 직후** | "이 유닛 주제를 실전으로" | `index.html` 유닛 완료 처리 |
| 3 | **점수별 학습 로드맵 섹션** (2,374행) | 이미 "로드맵" 콘텐츠가 있어 자연 결합 | 홈 새 카드 1개 |
| 4 | **`units/unit-NN.html` 하단** (30개) | SEO 유입이 곧 전환 지점 | 유닛 페이지 템플릿 1블록 |
| 5 | 오답노트 상단 | 자주 틀린 단어 → 관련 교재 | `index.html` |

### 1-3. UI 컴포넌트

- 카드 **1개**만. 상단에 `제휴` 또는 `광고` 라벨 명시.
- 링크 속성: `target="_blank" rel="sponsored noopener"`
  - 구글 정책상 유료 제휴 링크는 `sponsored` 표기를 권장한다.
- **쿠팡파트너스 고지 문구(필수)**:
  > 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
- 클릭 추적: Umami 커스텀 이벤트 `affiliate_click` (`data-umami-event`).

### 1-4. 구현 방법 (정적 사이트 제약 없음)

- 유닛 주제는 이미 `data/unitNN.js`에 존재 → **유닛 번호 → 추천 교재 매핑 테이블 1개**만 추가하면 동적 추천이 가능하다.
  ```
  const UNIT_BOOKS = { 1: [{...}], 2: [{...}], ... };
  ```
- 홈: `<section class="home-section">` 1개 추가.
- 유닛 페이지: 사전 렌더링 템플릿에 블록 1개 추가 (30개 일괄 생성).
- 서버·결제 연동 불필요 (링크만).

### 1-5. 리스크

- 광고가 많아지면 "학습 도구" 신뢰가 떨어진다 → **섹션 1개 원칙** 준수.
- 쿠팡파트너스는 고지 문구 누락 시 제재 대상이 될 수 있다.
- 제휴 정책·요율은 자주 바뀌므로 **분기 1회 점검** 필요.

## 2. 유료 부가자료 기획

### 2-1. 무료 / 유료 경계

| 구분 | 대상 |
|---|---|
| **무료 (영구)** | 웹 학습 전체 — 암기카드, 퀴즈, 시험모드, 오답노트, 진행률, TTS |
| **유료** | 웹 밖 자료 — PDF 단어장, 발음 MP3, 인쇄용 오답노트, 모의고사 문제지, Anki 덱 |

### 2-2. 상품 라인업 (가격은 제안)

| 상품 | 제안 가격 | 역할 |
|---|---|---|
| 유닛별 PDF 단어장 (30종) | 1,900 ~ 2,900원 | 진입(미끼) 상품 |
| **전체 1,000단어 PDF 단어장 + 발음 MP3** | **9,900원** | **주력 상품** |
| 오답노트 인쇄용 PDF | 3,900원 | 기존 기능의 프리미엄 출력 |
| 어휘 모의고사 5회분 | 5,900원 | 시험 대비 수요 |
| Anki/암기앱 덱 파일 | 3,900원 | 덕후층 |
| **번들 (전체 단어장 + 모의고사)** | **12,900원** | 객단가 상승 |

**PDF가 적합한 이유**: 서버 없이 배포 가능하고, 단어 데이터가 이미 `data/*.js`에 있어 **스크립트로 반복 생산**할 수 있다.

### 2-3. 결제·배포 경로

| 방안 | 장점 | 단점 |
|---|---|---|
| **스마트스토어** (PDF 판매) | 결제·자동 다운로드·환불 CS 내장, 신뢰도 | **사업자등록 필요**(전자출판업 58221 등), 수수료 4~6% |
| 자체 결제 (토스페이먼츠·카카오페이) | 마진 높음, 브랜드 통일 | 사업자등록 + 다운로드 링크 보호 구현 필요 |
| 외부 마켓 (크몽·탈잉) | 즉시 시작 가능 | 수수료 높음, 브랜드 종속 |

**권장**: 1단계는 **스마트스토어**(결제·배포·CS 자동화), 유입이 검증되면 자체 결제로 이전.

### 2-4. 제작 자동화

- `tools/make_workbook.py` 신규 제안 — `data/unitNN.js`를 읽어 유닛별·전체 PDF를 일괄 생성.
- 발음 MP3는 `edge-tts`(이미 `promo/`에서 사용 중)로 생성 가능 → **추가 비용 없음**.
- 한 번 만들면 재생산 비용이 거의 0이라 반복 판매에 유리하다.

### 2-5. 세무·법

- **반복·계속 판매 = 사업자등록 대상**, 종합소득세 신고 필요.
- 후원금과 달리 유료 판매는 후원자 세액공제 이슈가 없고, 매출 증빙이 명확하다.
- 디지털 상품은 청약철회 제한 고지(다운로드 개시 시 철회 불가)를 상품 페이지에 명시.

### 2-6. 측정 (Umami)

| 이벤트 | 목적 |
|---|---|
| `affiliate_click` (채널·위치 파라미터) | 제휴 영역별 클릭률 |
| `product_click` | 상품 관심도 |
| UTM (`?utm_source=store&utm_medium=site`) | 스토어 유입 추적 |

측정 없이 "효과 없다"고 판단하지 말 것 — 최소 2~4주 데이터를 모은다.

## 3. 실행 순서 (권장)

| 주차 | 작업 |
|---|---|
| 1주차 | 제휴 가입(쿠팡파트너스/알라딘 TTB) + 홈 로드맵 섹션에 교재 카드 1개 + FAQ 문구 정리 |
| 2주차 | 시험 결과 화면 추천 + `units/*.html` 하단 블록 + Umami 이벤트 |
| 3주차 | 전체 단어장 PDF 제작 + 스마트스토어 개설 |
| 4주차 | 측정 결과 확인 후 상품·배치 확장 |

## 4. KPI

- **제휴 클릭률** = `affiliate_click` / UV
- **상품 전환율** = 스토어 구매 / 스토어 유입(UTM)
- **웹 학습 지표 악화 여부** = 제휴 도입 전후 체류·재방문 비교

## 5. 하지 말아야 할 것

- 기존 무료 기능을 유료로 전환 (신뢰 붕괴)
- 후원을 주 수익원으로 기대 (전환율이 구조적으로 낮음)
- 제휴 링크를 여러 곳에 과다 배치 (학습 UX 저해)
- 고지 문구(`sponsored`, 쿠팡파트너스 문구) 누락
