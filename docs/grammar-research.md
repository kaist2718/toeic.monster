## 1. 조사 대상과 확인한 사실

### 1-1. 레벨 축으로 자료를 나누는 사이트

| 사이트 | 확인한 레벨 구성 | 배울 점 |
| --- | --- | --- |
| **British Council LearnEnglish** (`learnenglish.britishcouncil.org`) | 문법을 **A1-A2 / B1-B2 / C1** 세 묶음으로 나누고, 각 묶음에 문법 설명 + 상호작용 연습을 붙임. 별도로 전체를 아우르는 문법 레퍼런스를 둠 | 초급·중급·고급을 **CEFR 두 단계씩 묶어** 제시하는 방식이 학습자 진입을 쉽게 만든다 |
| **Perfect English Grammar** | 첫 화면에서 **A1 초급 / A2 기초 / B1 중급 / B2 중상급 / C1 고급**을 먼저 고르게 하고, 시제·조건문·화법·조동사·구동사를 **주제 허브**로 배치 | 레벨 선택과 주제 허브를 **두 축**으로 둔다. 시제를 특히 강조한다 |
| **BBC Learning English** | 문법을 **단원(unit) 단위**로 묶고 짧은 설명 + 영상/오디오 + 퀴즈를 붙임 | 한 단원 = 설명 + 예문 + 확인 문제의 3종 세트 |
| **EnglishPage / EnglishGrammar.org** | 시제 12개 표, 전치사·관사·조동사 같은 **문법 항목 사전식 정리** | 문법 용어가 익숙하지 않은 학습자를 위해 **표로 형태를 먼저** 보여 준다 |
| **Grammar Monster / Purdue OWL** | 규칙 + **흔한 실수(common mistakes)** 를 쌍으로 제시 | "왜 틀리는지"를 함께 보여 줘야 오답이 줄어든다 |
| **그래머 인 유즈(Basic/Intermediate/Advanced)** · **고딸영문법(왕기초·기초·중급)** | 한국 출간 문법서가 **3단계 시리즈**로 나뉘고, 각 단계가 100~150개 유닛 | 한국 학습자는 **왼쪽 설명 + 오른쪽 예문** 구조에 익숙하다. 단계 이름 자체가 검색 키워드가 된다 |

### 1-2. 조사에서 뽑은 5가지 설계 원칙

1. **단계는 "기초·중급·고급" 세 이름으로 고정** — 학습자 검색어와 가장 잘 맞고, `그래머 인 유즈`식 3단계 관행과도 일치한다.
2. **각 단계는 CEFR을 병기** — A1-A2 / B1-B2 / C1. 해외 자료와 눈높이를 맞추고, 어느 단계를 골라야 할지 판단 근거를 준다.
3. **한 과(unit)는 "도입 → 개념 → 형태 표 → 예문 → 흔한 실수 → 연습 문제"** — BBC의 3종 세트에 `흔한 실수`와 `연습 문제`를 더한다.
4. **문법 용어는 한국어로, 형태는 표로** — 말로만 설명하지 않고 표로 형태 변화를 먼저 보여 준다.
5. **예문은 실전 문장으로** — TOEIC·비즈니스 맥락을 유지해 어휘 콘텐츠와 이어진다.

### 1-3. 우리 사이트와의 관계

| 구분 | 기존 콘텐츠 | 이번 추가 콘텐츠 |
| --- | --- | --- |
| 성격 | `오늘의 문법 팁`(40개 한 줄 팁), `Part 5 빈출 문법 10가지`(전략 가이드) | **단계별 문법 교재 3권** (36과) |
| 분량 | 팁 1줄 / 항목 5개 | 과당 intro + 개념 6~7개 + 형태 표 + 예문 + 흔한 실수 5개 + 연습 8문항 |
| 목적 | 시험 직전 암기 | **문법 자체를 처음부터 쌓는 학습** |
| 진입 경로 | 앱 내 카드 | 검색 유입용 정적 페이지(`grammar/*.html`) |

기존 가이드는 "시험장에서 쓰는 요령"이고, 새 콘텐츠는 "문법의 뼈대"입니다. 서로 대체하지 않고 **난이도 사다리**로 연결합니다.

## 2. 설계한 3단계 커리큘럼

### 2-1. 초급 — 기초 영문법 (A1~A2, 12과)

영어 문장의 뼈대를 세우는 단계입니다. be동사와 일반동사부터 시작해 5형식까지 갑니다.

| 과 | 제목 | 핵심 내용 |
| --- | --- | --- |
| 1 | 문장의 뼈대와 be동사 | 주어 + 동사, am/is/are, 부정문·의문문 |
| 2 | 일반동사와 3인칭 단수 | do/does, -s 붙이기, 부정·의문 |
| 3 | 명사·관사·복수형 | a/an/the, 셀 수 있는/없는 명사 |
| 4 | 대명사와 소유 표현 | 인칭·소유격·재귀대명사 |
| 5 | 현재시제와 현재진행형 | 습관 vs 지금 하는 일 |
| 6 | 과거시제와 과거진행형 | 규칙·불규칙 동사, was doing |
| 7 | 조동사 기초 | can, may, must, should, have to |
| 8 | 형용사·부사와 비교 | -er/-est, more/most |
| 9 | 전치사와 시간·장소 | at/on/in, by/until |
| 10 | 의문문과 부가의문문 | 의문사, isn't it? |
| 11 | 부정문과 There is/are | 존재 표현, some/any |
| 12 | 문장의 5형식과 접속사 | SVO/Dative, and/but/because |

### 2-2. 중급 — 중급 영문법 (B1~B2, 12과)

시험 문법의 주력 구간입니다. 완료시제·수동태·관계사·준동사·가정법을 다룹니다.

| 과 | 제목 | 핵심 내용 |
| --- | --- | --- |
| 1 | 완료시제 3종 | 현재완료 / 과거완료 / 미래완료 |
| 2 | 수동태 | by + 행위자, 4형식·5형식 수동 |
| 3 | 관계대명사와 관계부사 | who/which/that, where/when/why |
| 4 | 부정사와 동명사 | to부정사 vs -ing, 동사별 선택 |
| 5 | 분사와 분사구문 입문 | 현재분사/과거분사, 접속사 + 분사 |
| 6 | 가정법 | if 가정법 과거·과거완료, I wish |
| 7 | 조동사 심화 | must have p.p., 추측 정도 |
| 8 | 사역·지각동사 | make/have/let, see + 목적어 + 원형 |
| 9 | 비교 심화 | the 비교급, 원급 관용 표현 |
| 10 | 간접의문문과 명사절 | what/if/whether, that절 |
| 11 | 화법 | 직접화법 → 간접화법 전환 |
| 12 | 연결어 심화 | 접속사 vs 접속부사 vs 전치사 |

### 2-3. 고급 — 고급 영문법 (C1, 12과)

시험·학술·비즈니스 문장에서 정확도를 결정하는 단계입니다.

| 과 | 제목 | 핵심 내용 |
| --- | --- | --- |
| 1 | 분사구문 심화 | 완료·수동 분사구문, 독립분사구문 |
| 2 | 도치 | 부정어 도치, 장소 도치, 양보 도치 |
| 3 | 가정법 심화 | 혼합 가정법, if 생략 도치, as if, but for |
| 4 | 명사절 심화 | that vs what, 동격의 that |
| 5 | 복합관계사 | whatever, whoever, however |
| 6 | 준동사의 완료·수동 | to have p.p., being p.p. |
| 7 | 강조·생략·대용 | It ~ that 강조, do 강조, 대부정사 to |
| 8 | 관계사 심화 | 계속적 용법, 전치사 + 관계대명사 |
| 9 | 시제 일치와 관용 | 시간·조건 부사절의 현재시제 |
| 10 | 어순과 정보구조 | 무게 중심 원리, 주제-초점 배열 |
| 11 | 접속사 심화 | 격식 양보·조건 표현, 상관접속사 |
| 12 | 담화 문법 | 연결 장치, 학술 문장의 응집성 |

## 3. 데이터·렌더링 구조

기존 사이트 규약을 그대로 따릅니다.

| 항목 | 결정 |
| --- | --- |
| 데이터 | `data/grammar-basic.js` · `data/grammar-intermediate.js` · `data/grammar-advanced.js` 가 `window.GRAMMAR_BOOKS` 에 교재를 하나씩 push |
| 생성 | `tools/build-pages.mjs` 가 `grammar/index.html`(허브) + `grammar/<id>.html`(교재 3권) 생성 |
| 검증 | `audit-site`(링크·앵커·사이트맵·문서 수치) · `audit-content`(과 번호·정답 보기 포함) · `audit-text`(맞춤법·TTS) |
| 진입 | 홈에 `📘 문법 교재` 섹션 + 섹션 이동 칩 |

### 3-1. 한 과의 데이터 구조

`도입(intro)` → `개념(points)` → `형태 표(table)` → `예문(examples)` → `흔한 실수(mistakes)` → `연습 문제(practice)`.
연습 문제는 정답과 해설을 `<details>` 로 접어 두어 스스로 풀고 확인할 수 있게 했습니다.

### 3-2. 앱과의 연동

| 기능 | 동작 |
| --- | --- |
| 예문 발음 | 정적 교재 페이지의 🔊 버튼. 앱의 `toeic1000_ttsvoice`·`toeic1000_ttslang`·`toeic1000_ttsrate` 를 그대로 읽어 **앱에서 고른 목소리·속도가 교재에서도 유지**됩니다 |
| 문법 문제 풀이 | 홈 `✏️ 문법 문제 풀이` 섹션에서 단계별 8문항. 기록은 `grammar_basic`·`grammar_intermediate`·`grammar_advanced` 키로 쌓이고 대시보드에서는 **문법** 한 영역으로 집계됩니다 |
| 문법 오답노트 | 틀린 문항(문제·보기·정답·해설·과)을 `toeic1000_grammarwrong` 에 저장. 홈에서 바로 보고 `📕 오답만 다시 풀기` 로 재시도할 수 있으며, 맞히면 자동으로 빠집니다 |
| 한 장 요약 | `grammar/cheatsheet.html` — 36과의 핵심 개념을 카드 한 장씩, 인쇄용 CSS 포함 |
