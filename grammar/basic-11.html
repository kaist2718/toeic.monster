11과 부정문과 There is / are🟢 초급

기초 영문법 · CEFR A1 ~ A2 · 총 12과 중 11번째

책 전체를 순서대로 보려면 기초 영문법, 같은 자리로 바로 가려면 책 페이지의 이 과를 쓰세요.

11과

부정문과 There is / are

There is / are로 어떤 것이 존재함을 말하고, some과 any로 수량을 표현합니다.

무엇이 있다·없다를 묻는 문제는 There is/are 구문이 단서입니다. some 과 any 의 쓰임을 같이 익혀 두면 안내문·공지 지문이 한결 쉬워집니다.

There is / There are 의 구분

뒤에 오는 명사가 단수면 There is, 복수면 There are를 씁니다. 뒤에 나열된 명사가 여러 개면 첫 번째 명사에 맞춥니다.

구조예문
There is + 단수There is a seminar today.
There are + 복수There are two openings left.
There is + 셀 수 없는 명사There is plenty of time.
There is + some + 단수There is some coffee in the pot.

💡 There is a pen and two notebooks on the desk. 처럼 여러 개가 나열되어도 첫 명사가 단수면 is 를 씁니다.

There 구문의 시제와 부정·의문

There 구문도 시제에 따라 be동사가 바뀌고, 부정문과 의문문은 be동사를 기준으로 만듭니다.

시제·형식형태예문
현재There is / areThere are three applicants.
과거There was / wereThere were several delays last week.
미래There will beThere will be a briefing tomorrow.
부정There is / are + notThere are not enough chairs.
의문Is / Are there ~?Are there any seats left?

💡 There is 뒤에는 단수 명사와 셀 수 없는 명사가, 복수 명사 뒤에는 There are 가 옵니다.

some 과 any

긍정문에는 some, 부정문과 의문문에는 any를 씁니다. 권유나 요청을 나타내는 의문문에는 some을 씁니다.

문장쓰는 말예문
긍정문someWe have some extra chairs.
부정문anyWe do not have any copies left.
일반 의문문anyDo you have any questions?
권유·요청someWould you like some coffee?
We have some extra chairs in the back.
뒤쪽에 여분의 의자가 있습니다.
Would you like some coffee?
커피 좀 드릴까요?

💡 기대나 권유가 담긴 의문문에는 some 을 씁니다. 권유하는 자리에서는 some 이 더 자연스럽습니다.

부정 표현의 정도 — no / none / hardly

no는 명사 앞에서 아예 없음을, not ~ any는 하나도 없음을 나타냅니다. none은 명사 없이 단독으로 쓰고, hardly, rarely는 부정의 뜻을 가진 부사입니다.

표현뜻예문
no + 명사하나도 없음There is no elevator in this building.
not ~ any하나도 없음We do not have any openings.
none (단독)아무것도 없음None of the applicants withdrew.
hardly / rarely거의 ~않다The manager rarely misses a meeting.
There is no elevator in this building.
이 건물에는 엘리베이터가 없습니다.
The manager rarely misses a meeting.
그 부장님은 회의를 거의 빠지지 않습니다.

💡 hardly, rarely 는 그 자체로 부정의 뜻이라 뒤에 not 을 쓰지 않습니다. 이중 부정이 되기 때문입니다.

부정문 만드는 법 정리

동사 종류에 따라 부정문을 만드는 위치가 다릅니다. be동사·조동사는 뒤에 not, 일반동사는 do / does / did 뒤에 not 을 붙입니다.

동사 종류부정문예문
be동사be + notThe office is not open yet.
일반동사 현재do / does + not + 원형She does not work on Fridays.
일반동사 과거did + not + 원형They did not attend the briefing.
조동사조동사 + not + 원형We cannot accept late applications.

💡 일반동사 부정문에서 동사는 항상 원형입니다. doesn't goes 는 틀린 형태입니다.

이중 부정은 쓰지 않기

한 문장에 부정 표현을 두 번 쓰면 뜻이 반대로 흐려집니다. 부정은 한 번만 쓰고, 나머지는 any나 ever로 바꿉니다.

We do not have any time left.
우리에게 남은 시간이 없습니다.
Nobody said anything about the change.
아무도 그 변경에 대해 말하지 않았습니다.

💡 I do not know nothing. 은 틀린 문장입니다. I do not know anything. 으로 씁니다.

⚠️ 자주 틀리는 포인트

  • There is many reasons. 처럼 복수에 is 를 쓰는 실수 — There are many reasons 입니다.
  • 긍정문에 any 를, 부정문에 some 을 쓰는 실수 — 긍정 some, 부정 any 가 기본입니다.
  • 이중 부정을 쓰는 실수 — I do not know nothing. 이 아니라 I do not know anything. 입니다.
  • There have / There has 로 존재를 말하는 실수 — 존재는 There is / are 로 씁니다.
  • none of 뒤에 단수 동사를 쓰는 실수 — 복수 명사에는 복수 동사를 씁니다.

✏️ 연습 문제 8문항

1. ____ are several positions available in the sales division.

  1. There
  2. It
  3. They
  4. Them
정답과 해설 보기

정답: There
복수 명사 앞에서 존재를 나타내므로 There are 를 씁니다.

2. Do you have ____ questions about the new policy?

  1. some
  2. any
  3. no
  4. much
정답과 해설 보기

정답: any
일반적인 의문문에는 any 를 씁니다.

3. There ____ a maintenance schedule posted near the entrance.

  1. are
  2. is
  3. were
  4. have
정답과 해설 보기

정답: is
뒤의 명사 a maintenance schedule 이 단수이므로 is 를 씁니다.

4. There ____ three delays on the shipping line last month.

  1. was
  2. were
  3. is
  4. has
정답과 해설 보기

정답: were
복수 명사와 과거 표현 last month 에 맞춰 were 를 씁니다.

5. ____ there any seats left for the morning session?

  1. Is
  2. Are
  3. Does
  4. Has
정답과 해설 보기

정답: Are
복수 명사 seats 에 맞춰 Are there 로 묻습니다.

6. We do not have ____ copies of the brochure left.

  1. some
  2. any
  3. none
  4. much
정답과 해설 보기

정답: any
부정문에는 any 를 씁니다.

7. The receptionist ____ checks the visitor log twice a day.

  1. hardly
  2. hard
  3. not
  4. no
정답과 해설 보기

정답: hardly
거의 ~않다라는 뜻의 부사는 hardly 입니다.

8. I do not know ____ about the schedule change.

  1. anything
  2. nothing
  3. something
  4. none
정답과 해설 보기

정답: anything
이미 do not 으로 부정했으므로 anything 을 씁니다. 이중 부정을 피합니다.
