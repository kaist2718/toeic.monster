11과 부정문과 There is / are🟢 초급

기초 영문법 · CEFR A1 ~ A2 · 총 12과 중 11번째

책 전체를 순서대로 보려면 기초 영문법, 같은 자리로 바로 가려면 책 페이지의 이 과를 쓰세요.

11과

부정문과 There is / are

There is / are로 어떤 것이 존재함을 말하고, some과 any로 수량을 표현합니다.

There is / There are의 구분

뒤에 오는 명사가 단수면 There is, 복수면 There are를 씁니다. 뒤에 나열된 명사가 여러 개면 첫 번째 명사에 맞춥니다.

구조예문
There is + 단수There is a seminar today.
There are + 복수There are two openings left.

some과 any

긍정문에는 some, 부정문과 의문문에는 any를 씁니다. 권유나 요청을 나타내는 의문문에는 some을 씁니다.

We have some extra chairs in the back.
뒤쪽에 여분의 의자가 있습니다.
Would you like some coffee?
커피 좀 드릴까요?

부정 표현의 정도

no는 명사 앞에서 아예 없음을, not ~ any는 하나도 없음을 나타냅니다. hardly, rarely는 부정의 뜻을 가진 부사입니다.

There is no elevator in this building.
이 건물에는 엘리베이터가 없습니다.
The manager rarely misses a meeting.
그 부장님은 회의를 거의 빠지지 않습니다.

⚠️ 자주 틀리는 포인트

  • There is many reasons. 처럼 복수에 is 를 쓰는 실수 — There are many reasons 입니다.
  • 긍정문에 any 를, 부정문에 some 을 쓰는 실수 — 긍정 some, 부정 any 가 기본입니다.

✏️ 연습 문제 3문항

1. ____ are several positions available in the sales division.

  1. There
  2. It
  3. They
  4. Them
정답과 해설 보기

정답: There
복수 명사 앞에서 존재를 나타내므로 There are 를 씁니다.

2. Do you have ____ questions about the new policy?

  1. some
  2. any
  3. no
  4. much
정답과 해설 보기

정답: any
일반적인 의문문에는 any 를 씁니다.

3. There ____ a maintenance schedule posted near the entrance.

  1. are
  2. is
  3. were
  4. have
정답과 해설 보기

정답: is
뒤의 명사 a maintenance schedule 이 단수이므로 is 를 씁니다.
