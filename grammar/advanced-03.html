03과 가정법 심화🔴 고급

고급 영문법 · CEFR C1 · 총 12과 중 3번째

책 전체를 순서대로 보려면 고급 영문법, 같은 자리로 바로 가려면 책 페이지의 이 과를 쓰세요.

03과

가정법 심화

시점이 섞인 가정에는 혼합 가정법을 쓰고, as if와 but for로 다양한 가정을 표현합니다.

가정법은 시제만 정확히 맞추면 실수할 자리가 많지 않지만, 시점이 섞이거나 조동사가 바뀌면 판단이 흔들립니다. 이 과에서는 세 시제의 기본형을 다시 세운 뒤 혼합 가정법과 대체 표현까지 넓혀 갑니다. 조동사 선택 기준도 함께 정리해 문맥에 맞는 문장을 고릅니다.

가정법 세 시제 한눈에 정리

가정법은 사실의 반대를 시제로 구분합니다. 현재 사실의 반대는 과거형, 과거 사실의 반대는 had p.p.를 씁니다. if절과 주절의 짝을 형태로 외워 두면 동사 자리를 묻는 문제가 빠르게 풀립니다.

시점if절주절예문
현재 사실의 반대동사의 과거형would + 동사원형If the plan were simple, we would start today.
과거 사실의 반대had + p.p.would have + p.p.If we had tested it, we would have found the bug.
실현 가능성이 낮은 미래were to + 동사원형would + 동사원형If the deal were to fall through, we would regroup.

💡 가정법에서 be동사는 주어와 상관없이 were 를 씁니다. If it was possible 보다 If it were possible 가 정확합니다.

혼합 가정법 — if절과 주절의 시점이 다를 때

if절은 과거를 가정하는데 주절의 결과가 현재에 미치는 경우에는 had p.p.와 would + 동사원형을 짝지어 씁니다. 반대로 if절이 현재를 가정하고 결과가 과거에 머무는 형태도 있습니다. 두 시점이 섞이는 순간이므로 if절과 주절을 따로 판단해야 합니다.

if절 시점주절 시점형태의미
과거현재had p.p. / would + 동사원형그때 그렇게 했더라면 지금은 ~할 텐데
현재과거동사의 과거형 / would have + p.p.지금 ~라면 그때 ~했을 텐데
과거과거had p.p. / would have + p.p.그때 그렇게 했더라면 그때 ~했을 텐데
If we had invested in automation, we would be more competitive now.
자동화에 투자했더라면 지금 더 경쟁력이 있을 텐데요.
If he were not so cautious, he would have taken the offer last year.
그가 그렇게 신중하지 않았다면 작년에 그 제안을 받았을 것입니다.

💡 now, today 같은 현재 시점 표지가 주절에 보이면 혼합 가정법을 먼저 의심합니다.

as if / as though

사실이 아닌 것을 마치 그런 듯이 표현할 때 씁니다. 현재 사실의 반대면 과거형, 과거 사실의 반대면 had p.p.를 씁니다. 실제로 그럴 가능성이 높으면 직설법 시제를 그대로 써도 되므로, 화자가 사실이라고 보는지가 시제를 가릅니다.

He speaks as if he owned the company.
그는 마치 회사를 소유한 것처럼 말합니다.
She looked as though she had not slept for days.
그녀는 며칠 동안 잠을 자지 않은 것처럼 보였습니다.
The machine sounds as if it needs repair.
그 기계는 수리가 필요한 것처럼 들립니다.

💡 as if 뒤에는 가정법 시제가 오지만, 실제 상황을 말할 때는 현재시제도 가능합니다. It looks as if it is going to rain. 처럼 씁니다.

but for / without / otherwise

but for와 without은 if it were not for의 뜻으로 뒤에 명사구를 두고 주절에는 would를 씁니다. otherwise는 앞 문장의 내용을 조건으로 받아 '그러지 않았다면'의 뜻을 만듭니다. 세 표현 모두 가정법을 대신하는 대표적인 장치입니다.

But for the intern's quick action, we would have lost the client.
인턴의 빠른 대응이 없었다면 고객을 잃었을 것입니다.
Without proper maintenance, the machine would break down often.
제대로 정비하지 않으면 그 기계는 자주 고장 날 것입니다.
The invoice was paid on time; otherwise the discount would have been lost.
송장은 제때 지급되었습니다. 그렇지 않았다면 할인을 받지 못했을 것입니다.

💡 but for 뒤에는 절이 아니라 명사구가 옵니다. 절을 쓰려면 If it had not been for the intern 으로 바꿉니다.

It is time / would rather / if only

It is time 뒤에는 과거형을 써서 지금 해야 할 일을 나타내고, would rather 뒤에도 과거형을 써서 현재의 소망을 표현합니다. if only는 '~라면 얼마나 좋을까'라는 강한 소망을 나타내며 시제 짝은 가정법과 같습니다.

표현뒤에 오는 형태예문
It is time + 주어동사의 과거형It is time we reviewed the safety protocol.
would rather + 주어동사의 과거형I would rather you handled the negotiation.
if only동사의 과거형 / had p.p.If only we had filed the claim earlier.
wish동사의 과거형 / had p.p.I wish the vendor had confirmed in writing.

가정의 강도에 따라 조동사 고르기

would는 결과와 의지, could는 능력과 가능성, might는 약한 가능성을 나타냅니다. 같은 가정이라도 조동사를 바꾸면 가능성의 정도가 달라지므로 문맥에 맞게 골라야 합니다. should는 격식 문어체에서 조건을 완곡하게 표현할 때도 씁니다.

조동사의미예문
would결과·의지We would reduce costs if we merged the teams.
could능력·가능성We could finish early if the data arrived today.
might약한 가능성The risk might fall if the supplier changed.
should완곡한 조건Should the vendor withdraw, we will rebid.

⚠️ 자주 틀리는 포인트

  • 혼합 가정법에서 if절에 과거완료 대신 과거형을 쓰는 실수 — 과거의 가정에는 had p.p. 를 씁니다.
  • It is time 뒤에 동사원형을 쓰는 실수 — It is time we review 가 아니라 It is time we reviewed 입니다.
  • 가정법에서 be동사를 was 로 쓰는 실수 — If it was possible 보다 If it were possible 가 정확합니다.
  • but for 뒤에 절을 두는 실수 — but for 뒤에는 명사구가 옵니다.
  • as if 뒤 시제를 직설법으로 고정하는 실수 — 사실의 반대를 나타낼 때는 과거형이나 had p.p. 를 씁니다.

✏️ 연습 문제 8문항

1. If the firm had adopted the new standard earlier, it ____ fewer compliance issues today.

  1. would have
  2. would have had
  3. will have
  4. had
정답과 해설 보기

정답: would have
과거의 가정이 현재 결과로 이어지는 혼합 가정법이므로 주절에 would + 동사원형을 씁니다.

2. The new hire talks ____ he had run the department for years.

  1. as if
  2. even if
  3. unless
  4. in case
정답과 해설 보기

정답: as if
사실이 아닌 것을 가정하는 as if 뒤에는 과거완료가 옵니다.

3. ____ the timely warning, the crew would not have evacuated.

  1. But for
  2. Because of
  3. In spite of
  4. Apart from
정답과 해설 보기

정답: But for
명사구를 두고 가정의 뜻을 나타내는 표현은 But for 입니다.

4. If the supplier ____ the revised terms, we would have signed last week.

  1. accepts
  2. had accepted
  3. accepted
  4. would accept
정답과 해설 보기

정답: had accepted
과거 사실의 반대를 가정하므로 if절에 had p.p. 를 씁니다.

5. It is time the committee ____ the safety report.

  1. reviews
  2. reviewed
  3. will review
  4. reviewing
정답과 해설 보기

정답: reviewed
It is time 뒤에는 과거형을 써서 지금 해야 할 일을 나타냅니다.

6. ____ the funding be cut, the pilot program will be suspended.

  1. Should
  2. Would
  3. Were
  4. Had
정답과 해설 보기

정답: Should
미래의 가능성이 낮은 조건을 완곡하게 표현할 때 Should 를 주어 앞에 둡니다.

7. Without the backup generator, the site ____ during the outage.

  1. would fail
  2. will fail
  3. fails
  4. failed
정답과 해설 보기

정답: would fail
without 뒤 명사구가 만드는 가정이므로 주절에 would + 동사원형을 씁니다.

8. I wish the branch ____ the revised policy before the audit.

  1. adopts
  2. had adopted
  3. will adopt
  4. adopting
정답과 해설 보기

정답: had adopted
이미 지난 일에 대한 소망이므로 wish 뒤에 had p.p. 를 씁니다.
