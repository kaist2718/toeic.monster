06과 과거시제와 과거진행형🟢 초급

기초 영문법 · CEFR A1 ~ A2 · 총 12과 중 6번째

책 전체를 순서대로 보려면 기초 영문법, 같은 자리로 바로 가려면 책 페이지의 이 과를 쓰세요.

06과

과거시제와 과거진행형

과거시제는 끝난 일을, 과거진행형은 과거의 어느 시점에 진행 중이던 일을 나타냅니다. 규칙 동사는 -ed를 붙이고, 불규칙 동사는 형태가 완전히 바뀝니다.

불규칙 동사는 외운 만큼 바로 점수가 됩니다. 규칙 동사의 -ed 철자와 발음, 불규칙 동사의 네 가지 유형을 표로 익히고, 지문에서 시제가 바뀌는 지점(날짜·시간 표현)을 표시하며 읽어 보세요.

규칙 동사의 과거형 — -ed 철자 규칙

대부분의 동사는 원형 뒤에 -ed를 붙여 과거형을 만듭니다. 동사 끝 철자에 따라 붙이는 방식이 달라지므로, 자주 쓰는 규칙을 먼저 익혀 둡니다. 과거분사도 규칙 동사는 같은 -ed 형태입니다.

동사 끝규칙예
일반-edwork → worked, start → started
묵음 ed 만 붙임arrive → arrived, decide → decided
자음 + yy → i + -edstudy → studied, apply → applied
모음 + y그대로 -edplay → played, stay → stayed
단모음 + 단자음자음을 겹치고 -edplan → planned, stop → stopped
-l 로 끝남-led (미국식)travel → traveled, cancel → canceled

💡 자음 + y 로 끝나면 y 를 i 로 바꾸고 -ed 를 붙입니다. study 는 studied 가 됩니다.

-ed 의 발음 3가지

과거형의 -ed는 세 가지로 발음됩니다. 목소리가 나가지 않는 소리 뒤에서는 /t/, 나는 소리 뒤에서는 /d/, t나 d 뒤에서는 /id/로 발음합니다. 소리로 익히면 듣기에서 시제를 놓치지 않습니다.

발음앞 소리예
/t/무성음 (p, k, f, s, ch, sh)worked, stopped, watched
/d/유성음 (모음, b, g, m, n, l, r)played, moved, opened
/id/t / dwanted, needed, decided

💡 t 나 d 로 끝나는 동사만 -ed 를 한 음절로 따로 발음합니다. wanted 는 두 음절입니다.

불규칙 동사의 네 가지 유형

불규칙 동사는 원형·과거형·과거분사가 어떻게 달라지는지에 따라 네 유형으로 나눌 수 있습니다. 유형을 알고 묶어서 외우면 개별로 외우는 것보다 오래 기억합니다.

유형형태예 (원형 / 과거 / 과거분사)
AAA세 형태가 모두 같음cut / cut / cut, put / put / put
ABB과거형 = 과거분사make / made / made, buy / bought / bought
ABA원형 = 과거분사come / came / come, run / ran / run
ABC세 형태가 모두 다름go / went / gone, write / wrote / written

💡 유형을 알아 두면 처음 보는 동사도 어느 묶음에 속하는지 짐작할 수 있습니다.

자주 쓰는 불규칙 동사 45선

토익·비즈니스 지문에 반복해서 나오는 불규칙 동사를 원형·과거형·과거분사와 함께 묶었습니다. 소리 내어 세 번씩 읽고, 표를 덮은 채 과거형을 되짚어 보세요.

💡 get 은 미국식 과거분사로 gotten 을 쓰고, 영국식은 got 을 씁니다. read 는 과거형도 철자가 같지만 발음이 /red/ 로 바뀝니다.

부정문과 의문문 — did

일반동사 과거의 부정문과 의문문에는 did를 씁니다. did가 시제를 대신하므로 본동사는 원형으로 돌아옵니다. 불규칙 동사도 did 뒤에서는 원형을 씁니다.

형식구조예문
부정문did not + 원형I did not finish the draft yesterday.
부정 축약didn't + 원형They didn't attend the briefing.
의문문Did + 주어 + 원형?Did you receive the updated schedule?
짧은 대답Yes / No + 주어 + didYes, I did. / No, she didn't.

💡 Did you received it? 는 틀린 문장입니다. did 뒤에는 반드시 원형 receive 를 씁니다.

과거진행형 — was / were + -ing

과거의 한 시점에 진행 중이던 일을 말합니다. was는 단수 주어에, were는 복수 주어와 you에 씁니다.

주어형태예문
I / He / She / Itwas + -ingI was preparing the report.
You / We / Theywere + -ingThey were waiting in the lobby.
부정문wasn't / weren't + -ingShe wasn't answering her phone.
의문문Was / Were + 주어 + -ing?Were you working from home yesterday?
They were waiting in the lobby at noon.
그들은 정오에 로비에서 기다리고 있었습니다.
I was preparing the report when the client called.
고객이 전화했을 때 저는 보고서를 준비하고 있었습니다.

💡 진행형에는 진행 중이던 시간 표현(at noon, all morning)이 함께 오는 경우가 많습니다.

과거시제와 과거진행형을 함께 쓰기

과거진행형과 과거시제를 함께 쓰면, 진행 중이던 일(배경)과 끼어든 일(사건)을 구분할 수 있습니다. 배경에는 while, 끼어든 일에는 when을 주로 씁니다.

접속사역할예문
when끼어든 짧은 사건The power went out when we were presenting.
while진행 중이던 배경While they were talking, the printer stopped.
as동시에 일어난 일She smiled as she opened the letter.
The team was working late when the server crashed.
서버가 멈췄을 때 그 팀은 늦게까지 일하고 있었습니다.
While the manager was reviewing the file, the phone rang.
부장님이 서류를 검토하는 동안 전화가 울렸습니다.

💡 while 뒤에는 진행형, when 뒤에는 과거시제가 오는 짝을 기억해 두면 빈칸이 빨리 풀립니다.

⚠️ 자주 틀리는 포인트

  • Did you received it? 처럼 did 뒤에 과거형을 또 쓰는 실수 — did 뒤에는 원형을 씁니다.
  • I was go to the meeting. 처럼 진행형에 원형을 쓰는 실수 — was going 이 맞습니다.
  • goed, buyed, teached 처럼 불규칙 동사에 -ed 를 붙이는 실수 — went, bought, taught 입니다.
  • 단모음 + 단자음 동사의 자음을 겹치지 않는 실수 — planed 가 아니라 planned 입니다.
  • yesterday 와 현재완료를 함께 쓰는 실수 — 끝난 과거 시점에는 과거시제를 씁니다.

✏️ 연습 문제 8문항

1. The shipment ____ yesterday afternoon.

  1. arrive
  2. arrived
  3. arrives
  4. arriving
정답과 해설 보기

정답: arrived
yesterday afternoon 은 끝난 과거 시점이므로 과거형 arrived 를 씁니다.

2. ____ the supplier confirm the delivery date?

  1. Did
  2. Does
  3. Was
  4. Were
정답과 해설 보기

정답: Did
일반동사 confirm 의 과거 의문문이므로 did 를 씁니다.

3. We ____ the presentation when the power went out.

  1. gave
  2. were giving
  3. give
  4. have given
정답과 해설 보기

정답: were giving
전원이 나간 순간 진행 중이던 일이므로 과거진행형을 씁니다.

4. Ms. Han ____ the report to the client last Friday.

  1. sends
  2. sent
  3. was sending
  4. has sent
정답과 해설 보기

정답: sent
last Friday 는 끝난 과거 시점이고 send 의 과거형은 sent 입니다.

5. The team ____ the new vendor before signing the contract.

  1. choose
  2. chose
  3. chosen
  4. choosing
정답과 해설 보기

정답: chose
과거의 동작이므로 choose 의 과거형 chose 를 씁니다.

6. I ____ the manual twice before calling support.

  1. read
  2. reads
  3. reading
  4. was read
정답과 해설 보기

정답: read
read 는 과거형도 철자가 같으며 발음이 /red/ 입니다.

7. The engineers ____ the prototype all night before the deadline.

  1. test
  2. tested
  3. were testing
  4. has tested
정답과 해설 보기

정답: were testing
밤새 계속되던 진행을 강조하므로 과거진행형을 씁니다.

8. The receptionist ____ the meeting room when the guests arrived.

  1. prepares
  2. prepared
  3. was preparing
  4. prepare
정답과 해설 보기

정답: was preparing
손님이 도착한 순간 진행 중이던 일이므로 과거진행형을 씁니다.
