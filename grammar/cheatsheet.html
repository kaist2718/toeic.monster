🔴 고급 · 고급 영문법 (CEFR C1)

  • 01과 분사구문 심화

    분사구문은 부사절의 접속사와 같은 주어를 생략해 만듭니다. 주절보다 앞선 일은 완료형, 당하는 관계는 수동형으로 쓰고, 주어가 다르면 독립분사구문으로 주어를 남깁니다.

    • 분사구문이 만들어지는 순서
    • 완료분사구문 — Having + p.p.
    • 수동분사구문 — Being + p.p. 와 생략
    • 부정분사구문 — Not + -ing
    • 독립분사구문 — 주어가 다를 때
    • with + 목적어 + 분사
    • 분사구문의 시제와 태 한눈에 정리

    부정어나 장소 부사구가 문두에 오면 조동사가 주어 앞으로 나갑니다. 주어가 대명사이거나 Only 뒤에 주어가 오면 도치하지 않습니다.

    • 부정어 도치의 기본 어순
    • Hardly ~ when / No sooner ~ than / Not until
    • 장소 부사구 도치
    • 양보 도치 — 형용사·부사·명사 + as/though
    • 가정법 도치 — If 생략
    • 도치가 일어나지 않는 경우

    • 가정법 세 시제 한눈에 정리

    • but for / without / otherwise
    • It is time / would rather / if only

    that절은 완전한 문장을, what절은 불완전한 문장을 이끕니다. 동격의 that으로 명사 내용을 설명하고, 요구·주장 동사 뒤에는 원형을 씁니다.

    • 전치사 뒤의 명사절
    • 간접의문문의 어순
    • whether 와 if 의 쓰임

  • 05과 복합관계사

    복합관계사는 선행사를 포함하며 명사절과 양보절을 이끕니다. -ever가 붙으면 '무엇이든, 누구든'의 뜻이 되고, however 뒤에는 형용사나 부사가 옵니다.

    • 복합관계사의 종류와 역할
    • 명사절을 이끄는 복합관계대명사
    • however + 형용사·부사
    • 양보의 복합관계부사
    • -ever 형태와 no matter 형태의 차이
    • 복합관계형용사 — whatever + 명사

  • 06과 준동사의 완료·수동·부정

    준동사는 시제와 태를 함께 표현할 수 있습니다. 완료형은 앞선 시점, 수동형은 당하는 관계를 나타내고, 부정은 준동사 앞에 not을 둡니다.

    • 완료부정사 — to have p.p.
    • 수동부정사 — to be p.p.
    • 수동동명사 — being p.p.
