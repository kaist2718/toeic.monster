TOEIC 어형 변화(품사 변환) 공략

한 어근이 명사·동사·형용사·부사로 바뀌는 규칙과 Part 5·6에서 빈칸 자리로 품사를 판단하는 방법을 정리했습니다.

Part 5·6 어휘 문제의 절반은 단어 뜻이 아니라 자리 싸움입니다. 접미사로 품사를 알아보고, 빈칸 앞뒤로 자리를 판단하는 두 가지만 익히면 오답이 크게 줄어듭니다.

🃏 단어·퀴즈로 바로 학습하기

빈칸 판단의 기본 규칙

  1. 빈칸 앞뒤를 먼저 봅니다. 관사 뒤면 명사, 조동사 뒤면 동사원형, 동사 뒤 목적어면 부사인 식으로 자리만 정해도 보기 절반이 지워집니다.
  2. 보기 네 개가 같은 어근의 다른 품사면 해석하지 말고 자리로 판단합니다. 해석부터 하면 시간이 두 배로 듭니다.
  3. 품사가 같은 보기가 둘 이상 남으면 문맥을 봅니다. 단수와 복수, 능동과 수동, 시제가 가리는 지점이 정답의 기준입니다.
  4. 빈칸이 두 개인 문항은 뒤 빈칸부터 봅니다. 뒤쪽이 더 명확한 단서를 주는 경우가 많습니다.

품사별 자리

  1. 관사·소유격·전치사 뒤 → 명사
  2. 주어 뒤·조동사 뒤·to 뒤 → 동사(원형)
  3. 명사 앞·be동사 뒤 → 형용사
  4. 동사·형용사·문장 전체 수식 → 부사

빈출 어형 세트

  1. success / succeed / successful / successfully
  2. decide / decision / decisive / decisively
  3. compete / competition / competitive / competitively
  4. analyze / analysis / analytical / analytically
  5. apply / application / applicant / applicable

주의할 함정

  1. -ly로 끝나도 형용사인 경우가 있습니다: costly, friendly, timely
  2. 명사와 형용사 형태가 같은 단어도 있습니다: available, reliable는 형용사만 있습니다.
  3. 수식 대상이 사람이면 -ed, 사물이면 -ing: confused staff / confusing instructions

빈칸 자리 판단 5초 규칙

  1. 빈칸 앞이 관사·소유격·전치사면 명사를 고릅니다.
  2. 앞에 주어가 있고 빈칸 뒤에 목적어가 있으면 동사를 고릅니다.
  3. 빈칸이 명사를 꾸미면 형용사를 고릅니다.
  4. 빈칸이 동사·형용사·문장 전체를 꾸미면 부사를 고릅니다.

접미사로 품사 빠르게 보기

  1. 명사 접미사: -tion, -ment, -ance, -ity, -ness
  2. 형용사 접미사: -ful, -ous, -ive, -able, -al
  3. 부사 접미사: -ly (다만 costly·friendly 는 형용사입니다)
  4. 동사 접미사: -ize, -ify, -ate

더 많은 어형 세트

  1. produce / product / production / productive / productively
  2. assist / assistance / assistant
  3. create / creation / creative / creatively
  4. inform / information / informative / informatively
  5. require / requirement / required

예문으로 확인하기

  1. The manager gave a detailed explanation. — 관사 뒤에는 형용사 + 명사가 옵니다.
  2. The team completed the project successfully. — 동사를 꾸미는 부사 자리입니다.
  3. Applicants must submit the form by Friday. — 조동사 뒤에는 동사원형.
  4. The company's performance was impressive. — be동사 뒤에는 형용사.

자주 묻는 질문

어형 문제는 뜻을 몰라도 풀리나요?

품사만 맞으면 정답인 경우가 많습니다. 보기에 같은 어근의 명사·형용사·부사가 나오면, 그 문항은 뜻이 아니라 자리를 묻는 문제입니다.

접미사는 다 외워야 하나요?

-tion/-ment/-ance 는 명사, -ive/-able/-ous 는 형용사, -ly 는 부사 정도만 익혀도 대부분 걸러집니다. 다만 friendly, likely 처럼 -ly 가 형용사인 예외는 따로 기억하세요.

관사 뒤에는 무엇이 오나요?

관사(a/the)와 형용사 뒤에는 명사가 옵니다. 이 두 자리만 눈에 익으면 Part 5 어형 문제를 빠르게 처리할 수 있습니다.
